# Release notes

## 1.0.0

- Initial release of Luminous, based on [Shopify Dawn](https://github.com/Shopify/dawn).
- Dark, neon-accent color palette and Work Sans typography.
- Homepage rebuilt for LED display sellers: spec highlights, category
  grid, featured products, quote call-to-action, FAQ.
- New `tech_specs` product block reading per-product metafields.
- New Request a Quote page and form (`quote-request-form` section,
  `page.quote-request` template).
