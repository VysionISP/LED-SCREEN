# Installation photos

Four renders for the homepage's **"See BrightSpan in action"** gallery
(the 4-column section between Featured displays and the quote
call-to-action). Each one already has the BrightSpan logo baked into the
top-left corner — that's fine at this size, it reads like a photo credit,
so no extra editing needed.

Upload each file to its matching column at **Online Store → Themes →
Customize → Home page → See BrightSpan in action**, in this order:

1. `installation-sports-lounge.webp` → "Sports bars & hospitality"
2. `installation-outdoor-plaza.webp` → "Outdoor plazas & venues"
3. `installation-retail.webp` → "Retail & showrooms"
4. `installation-corporate-lounge.webp` → "Corporate & VIP lounges"

Click each column block, then **Image**, to upload.
