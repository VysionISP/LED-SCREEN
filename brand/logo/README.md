# BrightSpan Displays logo

Generated wordmark + icon mark, transparent PNG, matching the theme's
color palette and Space Grotesk headings.

- `brightspan-logo-dark-bg.png` — primary lockup (white/cyan text). Use
  this one for the theme header/footer (dark background) and anywhere
  else with a dark or black background.
- `brightspan-logo-light-bg.png` — same lockup with dark navy/teal text,
  for white or light backgrounds (print, email signatures, partner decks).
- `brightspan-logo-black.png` — same lockup with plain black text (icon
  stays in color), a higher-contrast option for white backgrounds.
- `brightspan-icon-mark.png` — icon only, square, for the favicon,
  social/app icons, or anywhere the full wordmark is too wide.
- `logo-source.html` — editable source (plain HTML/SVG + Google Fonts).
  Open it in a browser to tweak colors or text, or hand it to a designer.

To use it on the storefront: Shopify admin theme editor → **Theme
settings → Logo** → upload `brightspan-logo-dark-bg.png` (the header is
dark by default in this theme). Upload a version of the icon mark as the
**Favicon** too.
